# Aurea Lounge UI

Create a premium, highly polished restaurant/café website UI inspired by the visual identity and content structure of Aurea Lounge (https://aurealounge.de/).

IMPORTANT: UI ONLY.
Do not build backend functionality, databases, authentication, APIs, reservation processing, CMS, or payment systems. Buttons, forms, navigation, and reservation elements can be visual UI components only.

## Brand / Creative Direction

The website should feel like a sophisticated European café that transforms naturally from a bright breakfast destination into an intimate evening lounge.

Core feeling:

* Warm
* Elegant
* Calm
* Sophisticated
* Intimate
* Premium but approachable
* Modern European hospitality
* “Golden hour” atmosphere throughout the entire day

Avoid:

* Generic startup layouts
* Overly futuristic UI
* Excessive gradients
* Neon colors
* Generic SaaS components
* Overly flashy animations
* Cold minimalist design

## Color Palette

Build the visual system around:

* Warm ivory / cream backgrounds
* Deep espresso / almost-black typography
* Muted champagne gold
* Brass accents
* Warm beige
* Subtle olive/green accents where appropriate

Gold should be used sparingly as a premium accent rather than dominating the interface.

## Typography

Use an elegant editorial serif font for large headlines and section titles.

Pair it with a clean modern sans-serif for:

* Navigation
* Buttons
* Menu items
* Prices
* Descriptions
* Small labels
* Contact information

Create strong typographic contrast between large sophisticated serif headlines and restrained sans-serif UI text.

## Overall Layout

Create a responsive, premium long-form restaurant landing page.

Desktop should feel editorial and spacious.

Mobile should preserve the same luxury atmosphere rather than simply stacking desktop components.

Use:

* Large imagery
* Asymmetrical layouts
* Generous whitespace
* Thin divider lines
* Small uppercase labels
* Large editorial headlines
* Elegant hover states
* Subtle scroll animations
* Rounded corners only where they genuinely improve the design

Do not make the website look like a template.

## Responsive Design

Desktop:

* Editorial layouts
* Large typography
* Full-width photography
* Asymmetric compositions

Tablet:

* Reduce spacing and typography while maintaining the editorial feel.

Mobile:

* Large readable headlines
* Full-width photography
* Horizontally scrollable menu categories
* Stacked experience sections
* Sticky compact navigation
* Comfortable touch targets

## Final Design Goal

The finished UI should feel like a high-end independent European café/lounge with a strong art direction.

It should communicate:

“Come for breakfast.
Stay for coffee.
Return for the evening.”

The design should feel bespoke, atmospheric and expensive — not like a generic restaurant template.
